# LensFlow – Photography & Media Management App 📸

تطبيق ويب احترافي ومتجاوب بالكامل لإدارة أعمال وشركات التصوير الفوتوغرافي والفيديو.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

---

## 🚀 المميزات الأساسية (Core Features)

- **دورة العمل المترابطة بالكامل**: `Client -> Booking -> Project -> Team -> Tasks -> Equipment -> Invoice -> Payment -> Statement`
- **واجهة عربية RTL بالكامل** مع إمكانية التبديل إلى الانجليزية LTR ودعم الوضع الليلي (Dark Mode).
- **محاكي الصلاحيات (Admin, Manager, Photographer, Videographer, Editor, Accountant)**.
- **نموذج طلب العميل وتوليد العرض المبدئي (Quotation)** في الوقت الفعلي.
- **التقويم التفاعلي (Interactive Calendar)** مع فحص التعارضات في المواعيد والمعدات المزدوجة.
- **إدارة مستودع المعدات والعهد (Equipment Inventory & Checkout)**.
- **نظام الفواتير الضريبية (VAT 15%) وكشف الحساب المطبوع (Account Statement)**.
- **تطبيق جوال قابل للتثبيت (PWA)** على شاشة الجوال مباشرة.

## 🛠️ التشغيل المحلي (Local Setup)

1. استنسخ المستودع (Clone repository):
   ```bash
   git clone https://github.com/yazeedabdulmonim-code/LensFlow-Photography-Management.git
   cd LensFlow-Photography-Management
   ```

2. تثبيت الحزم (Install dependencies):
   ```bash
   npm install
   ```

3. التشغيل المباشر (Start dev server):
   ```bash
   npm run dev
   ```

---

## 🌐 التثبيت والرفع على فيرسل (Deploy to Vercel)

1. سجل الدخول إلى [Vercel](https://vercel.com).
2. اضغط على **New Project** واختر المستودع `LensFlow-Photography-Management`.
3. اضغط على **Deploy** وسيتم تشغيل وسحب التطبيق كسيرفر مباشر فوراً!
